## Cómo Usar

### En la Vista de Alertas de Sonido

1. Ve a `/app/sounds`
2. Click en "📚 Usar de biblioteca"
3. Selecciona un sonido de la biblioteca
4. Configura el regalo, volumen y valor mínimo
5. Click en "Agregar Alerta"

### Agregar Más Sonidos

Para descargar más sonidos de Myinstants:

```bash
# Ejecutar el script de descarga
node download-more-sounds.js

# O agregar URLs manualmente al script y ejecutar
```

---

## Contribuir

Si deseas agregar más sonidos a esta biblioteca:

1. Visita [Myinstants](https://www.myinstants.com/)
2. Busca el sonido que deseas
3. Copia la URL del sonido
4. Agrégala al archivo `download-more-sounds.js`
5. Ejecuta el script
6. La metadata se actualizará automáticamente
